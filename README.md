# Astro Developer Portfolio

A modern, dynamic portfolio website showcasing AI Data Engineering expertise.

## Overview
This portfolio demonstrates expertise in building end-to-end agentic solutions for Fortune 500 clients. It features a "brag" video, project showcases, and technical implementation details.

## Tech Stack
- **Framework**: Astro
- **Styling**: Tailwind CSS
- **Content**: MDX files
- **Performance**: Zero JavaScript by default

## Key Features
- **Fast Loading**: Lightning-fast performance with Astro
- **Responsive Design**: Modern, mobile-first UI
- **Video Integration**: "Brag" video showcasing career transition
- **Project Showcase**: Interactive project cards with demos
- **Dark Mode**: System preference support
- **SEO-optimized**: Astro's built-in optimizations
- **Image Optimization**: Built-in image compression and loading
- **Content Collections**: MDX with frontmatter for structured data

## Project Structure
```
portfolio-website/
├── src/
│   ├── layouts/          # Main site layout
│   ├── components/       # Reusable UI components
│   ├── styles/           # CSS files
│   └── pages/           # Astro page components
├── public/               # Static assets
│   ├── videos/          # Brag and demo videos
│   └── images/          # Project screenshots
├── data/                # Project and resume data
└── content/            # MDX content files
```

## Getting Started

### 1. Clone This Repository
```bash
git clone https://github.com/your-username/portfolio-website.git
```

### 2. Install Dependencies
```bash
cd portfolio-website
npm install
```

### 3. Run Development Server
```bash
npm run dev
```

### 4. Build for Production
```bash
npm run build
```
